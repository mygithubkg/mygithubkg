### 🧠 Who I am

3rd-year **Electronics & Communication Engineering** student at **Punjab Engineering College, Chandigarh**.

I didn't start with AI. I started with Full-Stack — learning how systems talk to each other, why products break in production, what it actually takes to ship something real. Then I started integrating AI into those systems, and that changed how I think about building entirely.

**My path:**

```
Full-Stack  →  GenAI Integration  →  AI Systems in Production
```

I care about **why things work** — and more importantly, why they fail when you leave a clean notebook for a messy production environment. That gap is where I spend most of my time.
